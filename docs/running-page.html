0Просто поиграть

Ничего устанавливать не нужно.

Игра целиком живёт в двух файлах и открывается любым браузером. Если проект уже выложен — играть онлайн. Если скачали архив — распакуйте, зайдите в dist/ и откройте index.html двойным щелчком. Папки dist/ нет? Её создаёт сборка веб-версии, это раздел 5.

Звук. Музыка вступает только на этажах со стражами — это глубины 3, 4, 7, 8, 11, 12, 15 и 16. Ни один браузер не даёт звук до первого нажатия клавиши или щелчка по странице: это не поломка. Выключается кнопкой ♪ или клавишей M.

Сохранение живёт в самом браузере, поэтому продолжить партию можно только в том же браузере на том же устройстве.

1Что установить

Нужно только для сборки. Для игры в браузере — не нужно ничего.

Минимум: компилятор с поддержкой C++17 и CMake 3.16 или новее. Выберите систему — команды ниже переключатся вместе с ней.

  1. Скачайте Build Tools for Visual Studio — на странице внизу, в разделе «Tools for Visual Studio». При установке отметьте «Разработка классических приложений на C++». Всю Visual Studio ставить не обязательно.
  2. CMake обычно приезжает вместе с ними. Проверить можно в Developer Command Prompt for VS — он появится в меню «Пуск».
  3. Git: git-scm.com. Понадобится в разделе 6.

Все команды выполняйте в Developer Command Prompt, а не в обычном cmd: обычный не знает, где лежит компилятор. Это самая частая причина «ничего не работает» на Windows.

macOS
$ xcode-select --install        # компилятор Apple Clang
$ brew install cmake git        # нет Homebrew? brew.sh
Debian · Ubuntu · Mint
$ sudo apt update
$ sudo apt install build-essential cmake git
Fedora
$ sudo dnf install gcc-c++ cmake git

Проверка

Версии
$ cmake --version    # 3.16 или выше
$ g++ --version      # или clang++, или cl на Windows

3Собрать и запустить

Две команды: одна настраивает сборку, вторая собирает.

Linux
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DNAV_BUILD_TESTS=OFF
$ cmake --build build -j
$ ./build/nav
macOS
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DNAV_BUILD_TESTS=OFF
$ cmake --build build -j
$ ./build/nav
Developer Command Prompt
> cmake -S . -B build -DNAV_BUILD_TESTS=OFF
> cmake --build build --config Release
> build\Release\nav.exe

-DNAV_BUILD_TESTS=OFF отключает тесты — иначе CMake полезет в интернет за библиотекой GoogleTest. Если тесты нужны, это раздел 4.

Управление

hjkl yubn, стрелки, цифровой блокидти; шаг в тварь — удар
. или 5переждать ход
gподобрать
iкотомка: применить, надеть, снять
zколдовать
> <спуститься / подняться
pпринести жертву на капище
S Lсохранить / загрузить
T · ? · qязык · справка · выход

Партия начинается на перекрёстке — это глубина 0. Нечисти там нет: капище, лестница вниз и три вещи на постаментах. Взять можно ровно одну.

Партии без экрана

Проверка сборки
$ ./build/nav --demo 20    # двадцать полных партий ботом
$ ./build/nav --version

Строка demo ok в конце значит, что за все партии не сломался ни один инвариант и каждое сохранение прошло круговой обход. Бот сценарный и обычно умирает на третьем-четвёртом этаже: он умеет уходить от взгляда Вия, но не умеет отступать и лечиться вовремя.

4Прогнать тесты

CMake сначала ищет GoogleTest в системе, а если не находит — скачивает сам. Поэтому на первую сборку нужен интернет.

Developer Command Prompt
> cmake -S . -B build
> cmake --build build --config Release
> ctest --test-dir build --build-config Release --output-on-failure
macOS
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j
$ ctest --test-dir build --output-on-failure
Linux
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
$ cmake --build build -j
$ ctest --test-dir build --output-on-failure

Ожидаемое: 100% tests passed out of 459, примерно шесть секунд. Точная формулировка строки зависит от версии CMake; важно, что процент — сто. Следом ctest допишет, что Portability.PrintTheFingerprints не запускался: так и должно быть, это не тест, а служебная команда для обновления отпечатков подземелья.

Часть тестов
$ ctest --test-dir build -R Phases      --output-on-failure   # фазы боссов
$ ctest --test-dir build -R Lobby       --output-on-failure   # перекрёсток
$ ctest --test-dir build -R Portability --output-on-failure   # переносимость зерна
$ ctest --test-dir build -N                                   # список, без запуска

5Версия для браузера

Нужен Emscripten — компилятор C++ в WebAssembly.

Emscripten SDK
$ git clone https://github.com/emscripten-core/emsdk.git
$ cd emsdk && ./emsdk install latest && ./emsdk activate latest
$ source ./emsdk_env.sh      # Windows: emsdk_env.bat
$ cd ..

source ./emsdk_env.sh действует только в текущем окне терминала. В новом окне его нужно повторить — иначе emcmake «не найдётся».

Сборка и запуск
$ ./tools/build_web.sh
$ python3 -m http.server -d dist 8080

Откройте http://localhost:8080. В dist/ окажутся два главных файла: страница вместе с вшитыми спрайтами и музыкой, и движок, скомпилированный в WebAssembly. Рядом — ещё около 8 КБ: манифест, иконки и политика конфиденциальности, которые обязаны быть отдельными адресами. Всё это кладётся на любой статический хостинг без единой настройки.

Открывать dist/index.html напрямую через file:// не получится: браузеры не дают такой странице загружать соседний скрипт. Отсюда и локальный сервер в команде выше.

Перерисовать спрайты

Вся графика лежит текстом в tools/sprites/pixels.py: по шестнадцать строк на спрайт, точка — прозрачность.

Генератор
$ python3 tools/sprites/build.py

Пересобирает frontend/web/sprites.js и контактный лист docs/media/sprites.png. Для листа нужна Pillow (pip install pillow); без неё соберётся только первое.

6Выложить на GitHub

Пока репозитория нет, значки в шапке README и кнопка «Играть в браузере» не работают. Вот что нужно, чтобы заработали.

Создать репозиторий

  1. Откройте github.com/new.
  2. Имя — nav-roguelike. Именно такое: на него ссылается README.
  3. Публичный. Не ставьте галочки «Add a README», «.gitignore» и «license» — всё это в проекте уже есть.

Отправить код

Первый пуш
$ git init                 # если качали архивом
$ git add -A
$ git commit -m "Навь: роглайк на C++ и WebAssembly"
$ git branch -M main
$ git remote add origin https://github.com/TheToshix/nav-roguelike.git
$ git push -u origin main

Ветку можно назвать и main, и master — оба workflow'а слушают оба имени. У GitHub по умолчанию main, а репозиторий проекта живёт на master; если слушать только одно имя, второе останется вообще без проверок, а молчащий CI выглядит точно так же, как зелёный.

Если Git попросит пароль — обычный пароль GitHub больше не принимает. Нужен Personal Access Token: Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token, права repo. Токен вводится вместо пароля.

Включить Pages

В репозитории: Settings → Pages, в поле Source выбрать GitHub Actions — не «Deploy from a branch». Дальше всё само: workflow соберёт WebAssembly и опубликует игру при каждом пуше в main или master. Первая сборка идёт около пяти минут.

Проверить, что зелено

Вкладка Actions. Там семь задач: тесты на четырёх платформах, санитайзеры, покрытие, проверка, что спрайты не отстали от исходника, ESLint по коду страницы, замер тем стражей в headless-браузере и сборка WebAssembly. Зелёные галочки на главной странице репозитория — половина впечатления от портфолио.

Напоследок стоит заполнить описание репозитория (шестерёнка справа от «About»): короткая строка, ссылка на Pages и темы — roguelike, cpp, webassembly, gamedev, pixel-art.

7Если не собралось

Что видноЧто делать
cmake: команда не найдена CMake не установлен или не в PATH. На Windows — откройте Developer Command Prompt for VS, а не обычный cmd.
No CMAKE_CXX_COMPILER could be found Нет компилятора. Windows: не отмечен компонент «Разработка классических приложений на C++». macOS: не выполнен xcode-select --install.
CMake 3.16 or higher is required Старый CMake. На Ubuntu 20.04 и старше проще поставить с cmake.org, чем через apt.
Сборка падает на FetchContent или GoogleTest Нет интернета или он через прокси. Добавьте -DNAV_BUILD_TESTS=OFF к первой команде cmake.
В терминале кракозябры вместо букв Терминал не в UTF-8. Windows: chcp 65001 перед запуском. Ещё игра переключается на английский клавишей T.
Рамки и символы разъезжаются Нужен моноширинный шрифт с кириллицей: Cascadia Mono в Windows Terminal, Consolas или Lucida Console в старом cmd.
emcmake: команда не найдена Не выполнен source ./emsdk_env.sh в этом окне терминала. Он действует только до закрытия окна.
Страница открылась, но игра не запускается Файл открыт через file://. Поднимите сервер: python3 -m http.server -d dist 8080.
Нет звука Браузер ждёт первого нажатия клавиши. И музыка играет только на этажах со стражами: 3, 4, 7, 8, 11, 12, 15, 16.
git push не принимает пароль Нужен Personal Access Token — см. раздел 6.

Если что-то из написанного не сработало — это ошибка инструкции, а не ваша. Та же инструкция лежит в репозитории как docs/RUNNING.md и правится вместе с кодом.
